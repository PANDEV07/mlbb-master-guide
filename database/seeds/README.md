# Seeds Folder (`database/seeds/`)

Folder ini dikhususkan hanya untuk **data terverifikasi** (*verified game & esports datasets*).

**Aturan Ketat:**
- Dilarang memasukkan data dummy, statistik karangan, atau hasil pertandingan palsu ke dalam folder ini.
- Setiap berkas seed yang ditambahkan pada Phase 1+ wajib mencantumkan metadata patch, tanggal verifikasi, dan rujukan sumber.
